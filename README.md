# 🍬 Fang die Süßigkeiten! – Teste deine Reflexe!

**Ein süßes und schnelles Spiel, bei dem du deine Reflexe auf die Probe stellst!**

Wähle deinen Lieblingssnack und fang die Süßigkeiten, die auf deinem Bildschirm erscheinen – bevor sie wieder verschwinden! Aber sei schnell, der Timer tickt. Je mehr Süßigkeiten du fängst, desto mehr Punkte bekommst du. Kannst du den höchsten Punktestand erreichen?

## ✨ Features

- 🍩 Wähle aus vier leckeren Snacks
- ⏱️ Teste deine Reflexe gegen die Uhr
- 🎶 Lustige Soundeffekte, wenn du eine Süßigkeit fängst
- 🏆 Versuche, den höchsten Punktestand zu erreichen

## 💡 Idee

Fang die Süßigkeiten wurde als Spaßspiel für schnelle Reaktionen entwickelt. Es bietet eine Menge Spaß für zwischendurch – ideal, um deine Reflexe zu trainieren oder einfach ein kleines Spiel zu genießen.

## 🛠️ Technologien

- **HTML**
- **CSS** (Animationen & Design)
- **JavaScript** (Spiellogik & Interaktionen)

## 📁 So funktioniert’s

1. Öffne `index.html` in deinem Browser.
2. Wähle deinen Lieblingssnack.
3. Fang die Süßigkeiten, bevor sie verschwinden!
4. Versuche, den höchsten Punktestand zu erreichen.
