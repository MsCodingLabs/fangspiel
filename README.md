# 🍬 Fang die Süßigkeiten! – Teste deine Reflexe!

Ein süßes, actionreiches Spiel, das deine Reflexe auf die Probe stellt! Wähle deinen Lieblingssnack und fang die Süßigkeiten, die auf deinem Bildschirm erscheinen – aber sei schnell, der Timer läuft!  
Je mehr du fängst, desto mehr Punkte sammelst du. Doch Vorsicht: Die Süßigkeiten verschwinden schneller, je besser du wirst!  
Mit lustigen Soundeffekten und einer Menge Spaß, ist dieses Spiel perfekt, um deine Reaktionsgeschwindigkeit zu testen oder einfach mal zwischendurch abzutauchen.

## 🛠️ Technologien:

3. Fang die Süßigkeiten, bevor sie wieder verschwinden!  
4. Versuche, den höchsten Punktestand zu erreichen!
